A make.fun entry for the "Green Tests, Nothing Works: The Excuse Contest" bounty: the funniest one-line excuse for all-green tests while nothing works, in under 140 characters.

> The tests pass because I wrote them to the code, not to the requirements. The code is fine. The product is a rumour.

## How to run

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` and prints the character count (116).

## Why this line

It dodges the usual mocks-and-coverage jabs and finds a sharper, truer failure: tests written against the code instead of the requirements. The three short beats escalate cleanly, and "the product is a rumour" lands as the kind of line a tired engineer would repeat at standup. The excuse is funny because it is almost a confession.
